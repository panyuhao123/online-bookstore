# DESIGN.md —— 线上书店（当当风格）

> 本文件是本项目 PC 商城端（`bookstore-web`）的设计规范，按 Google Stitch
> DESIGN.md 的 9 段格式组织，供 AI 编码时作为唯一视觉依据。
>
> **来源说明**：`awesome-design-md` 技能库里没有 dangdang 的现成参考文件
> （库里 54 套都是开发者产品站），所以这一份是**参照当当网实际视觉语言**归纳的，
> 不是从技能库拷来的。技能库中可类比的参考是 `pinterest.md`（红色强调色 + 图片网格）

## 1. Visual Theme & Atmosphere

**关键词**：中国综合电商、信息密集、促销导向、零装饰。

当当是「书架式」首页：一屏之内把**分类入口、活动位、榜单、特惠**全部铺开，
用密度换取「总有一个入口你会点」。它不追求留白与呼吸感 —— 那是品牌官网的做法，
电商首页的留白等于浪费曝光位。

三条基调：

1. **一片灰底 + 若干白块。** 页面底色是中性灰（`#f5f5f5`），内容块一律纯白直角卡片，
   靠 1px 边框分隔，**不靠阴影**。阴影只在 hover 时出现，用来表达"这块可以点"。
2. **红色只给价格和主按钮，橙色只给导航与购物车。** 两种暖色分工明确，
   红 = 钱，橙 = 路。混用会让页面变成一锅番茄汤。
3. **字号偏小、行高偏紧。** 正文 12px、标题 14px。这是电商的必然：
   同屏塞进 40 个商品名，字号就必须让步。

**反向约束**：不要加大圆角、不要用玻璃拟态、不要用大留白、不要给卡片加悬浮阴影做静态呈现。

## 2. Color Palette & Roles

| Token | Hex | 角色 |
| --- | --- | --- |
| `--brand` | `#ff2832` | 主红。价格、主按钮、楼层标题装饰条、「限时特惠」标签 |
| `--brand-dark` | `#e6162d` | 主红 hover/active |
| `--brand-weak` | `#fff1f0` | 浅红底。选中态背景、价格区块底 |
| `--orange` | `#ff6f00` | 导航条底色、搜索按钮 |
| `--orange-light` | `#ff8f00` | 导航条 hover、购物车按钮渐变另一端 |
| `--text-primary` | `#333333` | 书名列、楼层标题 |
| `--text-regular` | `#666666` | 正文、作者、辅助信息 |
| `--text-sub` | `#999999` | 次要说明、评论数 |
| `--bg-page` | `#f5f5f5` | 页面底色 |
| `--bg-card` | `#ffffff` | 卡片、header |
| `--bg-fill` | `#f7f7f7` | 输入框内底、表头 |
| `--border` | `#e5e5e5` | 卡片边框、分割线（**主要分隔手段**） |
| `--border-light` | `#f0f0f0` | 卡片内部细分隔（虚线优先） |

语义规则：

- **价格**永远是 `--brand`，前缀 `¥`，字号比书名大 2px，加粗。
- **划线原价**用 `--text-sub` + `line-through`，紧跟在售价右侧。
- **售罄/仅剩**用红底白字小标签贴封面左上；**热销/好评/包邮**用浅红底红字。
- **不要在深色底上放红色文字**（对比度不足），导航条内的文字一律白色。

## 3. Typography Rules

字体族：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
（不引入 Web Font —— 中文 Web Font 体积不可接受，且系统字体已足够。）

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 楼层主标题 | 18px / 24px | 700 | 楼层左栏 `h2`（「小说」「计算机」） |
| 页面标题 | 16px / 22px | 700 | 「购物车」「我的订单」 |
| 商品名 | 12px / 18px | 400 | 卡片书名，**最多两行**，超出省略 |
| 正文 | 12px / 20px | 400 | 作者、出版社、描述 |
| 价格 | 18px / 22px | 700 | 详情页售价；卡片内 16px |
| 辅助 | 12px / 18px | 400 | 评论数、销量、时间 |
| 顶栏 | 12px / 32px | 400 | 工具条（`#666`）与导航条（`#fff`） |

**不要用 300 字重**（Windows 上中文细体渲染发虚，这是 Stripe 式设计在中文环境的经典翻车点）。

## 4. Component Stylings

### 4.1 顶部工具条（`topbar`）

高 32px，`--bg-fill` 底，1px 下边框。左：欢迎语 + 登录/注册 + 我的订单 + 我的书单 + 浏览历史；
右：图书对比（带数字）+ 购物车 + 客服。字号 12px，`--text-regular`，hover 变 `--brand`。
**不加任何图标**（这一行是纯文字密度区，加图标反而挤）。

### 4.2 主 header（`site-header`）

高 96px，白底。三栏：logo（220px）→ 搜索区（flex）→ 购物车按钮（180px）。

- **logo**：纯文字「线上书店」24px/700 + `--brand` 色，左侧一个红色圆角方块放白色书本图标。
  不做图片 logo（项目没有品牌资产，文字 logo 更稳）。
- **搜索区**：`分类下拉（80px）+ 输入框（flex）+ 橙色按钮（90px）` 三者拼成一个整体，
  共享 2px `--orange` 边框，内部无间隙，圆角只在外侧。**这是当当最标志性的一个组件。**
  下方一行热搜词（12px，`--text-sub`，hover 变红）。
- **购物车按钮**：`--orange → --orange-light` 渐变，白字，高 40px，右上角数量徽标。

### 4.3 导航条（`nav-bar`）

高 36px，`--orange` 底，白字。
左端一块**深红**的「全部商品分类」（宽 220px，与左侧分类树对齐），右侧横向菜单。
最右放「限时特惠」红底小块。hover 背景 `--orange-light`。

### 4.4 分类树（`cat-tree`）

宽 220px，白底，高与轮播齐平（360px）。每行 30px，12px 字。
hover：背景 `--brand-weak`，文字变红，右侧出现 `›`，并弹出二级面板
（面板内是该分类销量前 4 的书名 + 价格）。

### 4.5 图书卡片（`book-card`）

白底，1px 边框，**直角**（`--radius-sm: 2px`），内边距 10px。
结构：封面 3:4 → 书名两行 → 作者一行 → 评分 → 价格（左）与对比标记（右）。
hover：边框变 `--brand`，封面轻微放大（1.03），**不位移**（位移会让密集网格抖动）。

### 4.6 楼层（`floor`）

两栏：左栏 160px（分类名 + 若干子分类链接 + 「查看更多」），右栏网格 5 列。
左栏底色 `--bg-fill`，与右侧白底形成"书架隔板"的观感。
**楼层标题左侧有一条 4px 红色竖条** —— 这是全站唯一的装饰性元素，不要复制到别处。

### 4.7 按钮

- 主按钮：`--brand` 底，白字，2px 圆角，高 32px。
- 次按钮：白底，`--border` 边框，`--text-regular` 字，hover 边框变红。
- 文字链接：`--brand`，hover 加下划线。
- **不要用胶囊按钮**（`border-radius: 999px`）—— 那是社交产品的语言，电商用直角。

## 5. Layout Principles

- 容器：`max-width: 1200px`，居中，左右 padding 0（内容块自己对齐栅格）。
- 间距刻度：`4 / 8 / 12 / 16 / 20 / 30`。区块之间 20px，楼层之间 30px。
- 首屏三栏：`220px | 1fr | 240px`，间距 10px。
- 楼层：`160px | 1fr`，间距 0（左栏贴边，靠底色区分）。
- 商品网格：5 列，列间距 10px，**行间距 10px**（比列间距大是浪费，电商要的是密）。

---

## 6. Depth & Elevation

只有两级：

- **L0**：平铺卡片，1px `--border`，无阴影。
- **L1**：hover/浮层，`0 2px 8px rgba(0,0,0,.12)`。

**禁止**：多层阴影、彩色阴影、内阴影。当当的层次完全靠边框与底色对比建立，
阴影只作为"可以点"的瞬时反馈。

---

## 7. Do's and Don'ts

**Do**

- 用边框分隔，而不是阴影。
- 价格永远红色、永远比书名大。
- 一屏之内给出尽可能多的**可点入口**（分类、榜单、特惠、推荐）。
- 中文文案短句直给（「满 99 免运费」而不是「订单满 99 元即可享受免运费服务」）。

**Don't**

- 不要大圆角、不要胶囊按钮、不要玻璃拟态。
- 不要给静态卡片加阴影。
- 不要在语义上混用红与橙（红=价格/主操作，橙=导航/购物车）。
- 不要把留白当高级感 —— 电商首页的空白就是流失的曝光。
- 不要为「好看」删掉功能入口（这是毕设，功能完整性优先于视觉纯度）。

## 8. Responsive Behavior

| 断点 | 行为 |
| --- | --- |
| ≥1200px | 三栏首屏；楼层 5 列 |
| 992–1199px | 首屏隐藏右栏（240px），轮播撑满；楼层 4 列 |
| 768–991px | 隐藏左侧分类树；搜索区降为一行；楼层 3 列 |
| <768px | 单列；导航条横向滚动；工具条只留「登录/购物车」 |

触控目标最小 32×32。表格类页面（订单、地址）在 <768px 改为卡片流。

## 9. Agent Prompt Guide

**快速色板**：`#ff2832` 红 / `#ff6f00` 橙 / `#f5f5f5` 底 / `#e5e5e5` 边框 / `#333` 主文字。

**可直接粘贴的提示词**：

> 按 `DESIGN.md` 的当当风格改这个页面：1200px 容器、灰底白块、1px 边框代替阴影、
> 价格用 #ff2832 且比书名大、导航条 #ff6f00 白字、圆角 2px、正文 12px。
> 保留所有既有功能入口与下列 DOM 契约：`.banner-slide` / `.floor` / `.floor-title h2` /
> `.book-grid .book-card` / `.badge-strip .badge-item` / `.search-suggest-popper .sug-item`。
> 不要新增图片资源，不要引入 Web Font。

**DOM 契约说明**：`tools/verify_web_pc.cjs`（28 项端到端断言）依赖上述 class 名，
改版时**可以改样式、不能改这些类名**，否则门禁会红。
