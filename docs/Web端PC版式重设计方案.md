# Web 端 PC 版式重设计方案

## 一、背景与目标

当前 Web 端已实现「同工程 H5 + 响应式断点 ≥960px」的基础 PC 骨架，但页面仍偏向"大屏版 APP"：

- 首页只有 Banner + 宫格 + 楼层，缺少 PC 商城标志性的左侧分类树、右侧榜单/快报；
- 分类页、列表页、搜索页没有面包屑与左侧筛选面板；
- 详情页左图右文虽已完成，但缺少 PC 购买面板的促销/库存/服务承诺等模块；
- 购物车仍是移动端卡片行，未做 PC 电商标准的表格；
- 结算/订单/地址等表单页仍是单列流，未做 PC 常见的左右分栏或窄卡片居中。

**本次重设计目标**：在既有 uni-app H5 工程内，参考京东、当当等成熟图书电商 PC 版式，做一套真正的"网页商城"桌面布局；<960px 完全回退到现有 APP 移动端样式，不破坏已验证效果。

## 二、参考对象与可借鉴点

| 标杆 | 可借鉴 | 本项目落地方式 |
| --- | --- | --- |
| **当当图书 PC 首页** | 顶部窄条 + 主导航 + 搜索框 + 购物车；左侧商品分类树；中间 Banner；右侧榜单/入口 | 复用 `web-header` 两段式；首页新增左侧分类树 + 中间 Banner + 右侧榜单 |
| **京东图书 PC 列表/分类页** | 面包屑导航；左侧分类/价格/评分筛选面板；顶部排序条；网格/列表视图 | 新增 `<bread-crumb>` 组件；分类页桌面改为左侧分类树 + 右侧结果；列表页加顶部面包屑 + 排序 |
| **京东/当当 详情页** | 面包屑 + 左侧大图 + 右侧购买面板（价格/促销/服务/数量/按钮）+ 下方评价 | 详情页补面包屑；右侧面板提取为信息模块，加服务承诺/库存/促销标签 |
| **京东/淘宝 购物车 PC** | 表格列：勾选/商品信息/单价/数量/小计/操作；底部结算条；右侧推荐/结算卡 | 购物车桌面改用表格布局；底部结算条居中 |
| **当当 个人中心/订单** | 左侧二级菜单 + 右侧内容卡；订单列表表格化；地址卡片网格 | 个人中心、订单列表、地址列表桌面化 |

**不照搬的边界**：

- 不复制任何素材、配色、图标、Logo，沿用本项目朱砂红 `#C8362F` Token；
- 不做实时个性化推荐（无算法后端），榜单用已有接口 `sort=sales/new/price_asc` 取 TOP N；
- 不做复杂 hover 下拉菜单动画，用 CSS 简单展开，避免跨端兼容风险；
- 不新增独立工程，仍在 `bookstore-app` 内通过条件编译/媒体查询实现。

## 三、设计原则

1. **断点统一**：PC 断点仍用 `≥960px`（与 `rpxCalcMaxDeviceWidth` 对齐），大屏 `≥1280px` 加列数。
2. **内容居中**：PC 主内容区最大 `1200px`，fixed 元素用 `padding-inline: max(...)` 对齐，避免 transform 破坏定位。
3. **组件复用**：图书卡片 `book-card`、楼层标题 `floor-title`、Banner `home-banner` 等仍复用，仅通过 CSS 调整 PC 下的尺寸与列数。
4. **移动端零侵入**：所有 PC 样式集中到 `common/web.scss`，PC 专用组件用 `v-if="isWide"`，移动端不渲染也不执行无关逻辑。
5. **渐进增强**：新组件先用真实接口数据；接口缺失时优雅降级为空态或隐藏模块。

## 五、关键新增/改造组件

### 5.1 面包屑 `<bread-crumb>`

- 支持传入路径数组 `{name, route?}`；最后一项不可点。
- 桌面显示于 `.page` 内部顶部，移动端不渲染。
- 当前页面 route 可自动高亮主导航。

### 5.2 PC 分类树 `<web-category-tree>`

- 复用 `/api/category/list` 数据（与移动端 `pages/category/category.vue` 同源）。
- 一级分类纵向列表，当前项高亮；悬停/点击展开二级子分类。
- 首页用于首屏左侧快速导航；分类页用于左侧主导航。

### 5.3 PC 榜单 `<web-rank>`

- 调用 `pageBooks({ pageSize: 5/10, sort: 'sales'|'new'|'price_asc' })`。
- 显示名次（1/2/3 金/银/铜色）、书名、价格。
- 用于首页右侧"热销榜"、分类页右侧"本类热销"。

### 5.4 PC 购买面板（详情页右栏）

- 标题区：书名 + 作者出版社 + 分类标签；
- 价格区：当前价 + 划线原价（如 book.originalPrice）+ 折扣标签；
- 服务/库存区：库存状态、服务承诺（正品保证、7天无理由、快速发货）；
- 数量区：步进器 + 库存提示；
- 按钮区：加入购物车（outline）+ 立即购买（primary），售罄态统一处理。

### 5.5 PC 购物车表格

- 表头：全选、商品信息、单价、数量、小计、操作；
- 行：勾选框 + 封面缩略图 + 书名/库存 + 单价 + 步进器 + 小计 + 删除；
- 底部：合计、已选件数、去结算按钮；
- 未登录提示条保留。

## 六、各页面改造点

### 6.1 `pages/index/index.vue`

桌面下首屏改为三栏：

```
.web-hero
├── .web-hero-side   (分类树)
├── .web-hero-main   (Banner + 入口条)
└── .web-hero-extra  (热销榜 TOP 5)
```

- 分类树：`<web-category-tree>`；
- Banner：保持 `home-banner`，桌面高度可略降或保持；
- 入口条：将 `entry-grid` 在桌面下改为横向 4 格；
- 楼层：`floor-title` 加底边分隔，卡片列数与现有 `web.scss` 一致。

### 6.2 `pages/category/category.vue`

桌面下改为"左右分栏"：

- 顶部：`bread-crumb` + 当前分类标题；
- 左侧：`<web-category-tree>` 一级分类树 + 当前分类子分类；
- 右侧：排序条 + 图书网格 + 分页提示。

移动端保持现有侧栏切换不变。

### 6.3 `pages/book/list.vue`

桌面下：

- 顶部 `bread-crumb`；
- 左侧可选筛选面板（当带 `categoryId` 时显示分类名，搜索时不显示）；
- 排序条改为顶部横向按钮组；
- 结果统计（"共 N 本"）前置。

### 6.4 `pages/book/detail.vue`

桌面下：

- 顶部 `bread-crumb`；
- 封面区左栏 `flex: 0 0 420px`；
- 右栏购买面板模块化（价格/服务/数量/按钮），按钮改为横向并排并加大；
- 简介与评价作为下方区块，宽度与右栏对齐。

### 6.5 `pages/cart/cart.vue`

桌面下：

- 顶部 `bread-crumb` + 页面标题；
- 商品列表改为表格，表头 sticky；
- 底部结算条内容居中；
- 空态保留。

### 6.6 `pages/order/list.vue`、`pages/order/detail.vue`、`pages/address/list.vue`、`pages/mine/mine.vue`

桌面下改为：

- 面包屑 + 页面标题；
- 个人中心：左侧快捷菜单（我的订单/地址/评价）+ 右侧信息卡；
- 订单列表：卡片横向排布或表格；
- 地址列表：卡片网格；
- 结算页：左右分栏（左侧地址+商品，右侧汇总+提交）。

## 九、风险与回退

| 风险 | 规避措施 |
| --- | --- |
| uni-app H5 不支持复杂 hover 下拉动画 | 用纯 CSS `:hover` 简单展开，移动端不渲染 |
| 断点临界处布局抖动 | 断点与 `rpxCalcMaxDeviceWidth=960` 对齐；关键布局用 `px` 覆盖 |
| 新增组件破坏移动端 | 所有 PC 组件加 `v-if="isWide"`，样式写在 `@media (min-width: 960px)` 内 |
| 页面结构改动导致 `check_app_sfc.cjs` 失败 | 每次改完跑脚本，预期失败项仍只保留 `common/config.js` |
| 后端接口返回字段缺失（如 originalPrice） | 字段缺失时不展示划线价/折扣，不阻断购买流程 |
| 覆盖现有已验证截图 | 保留 `tools/web_*_before_redesign.png` 备份，用于回归比对 |

## 十一、v2 评审意见落地记录

> 首轮样图评审后，逐条对照京东 / 当当 PC 书城补齐的短板。下面记录「用户提的问题 → 处理结论」，
> 其中带 ⚠️ 的是受后端字段限制、做了降级处理的项。

### 11.1 首页

| 评审意见 | 处理结论 |
| --- | --- |
| 左侧分类是纯文字列表，没有二级展开 | ✅ 新增 `components/web-category-tree.vue`：手风琴展开二级、首屏只显示 8 个一级 + 「更多分类」折叠 |
| Banner 是静态文本，没有轮播 | 说明：`home-banner.vue` **本来就是 3 张 swiper + 圆点指示器**，首轮样图画成静态是绘图疏漏；本次把它在桌面并入三栏首屏 |
| 热销榜没有「完整榜单」入口 | ✅ 新增 `components/web-rank.vue`，底部「完整热销榜 ›」跳列表页并带同一排序 |
| 快捷入口符号 `≡ ☰ ★ ¥` 表意弱 | 说明：项目**本来就用** `entry-icon.vue` 的 CSS 图形图标，样图中的符号是绘图疏漏；本次桌面入口条内边距 16→22px、图标 36→40px 并补 hover 底色 |
| 商品卡片信息密度高、留白不足 | ✅ 卡片 hover 增加品牌色描边（原已有上浮 + 阴影）；书名 15px、出版社弱化、间距加大 |

### 11.2 分类 / 列表页

| 评审意见 | 处理结论 |
| --- | --- |
| 价格筛选没有自定义输入框 | ✅ 新增 `components/web-filter-panel.vue`：快捷区间 + 最低/最高价输入，对接接口已有的 `minPrice/maxPrice`，填反自动对调 |
| 缺少出版社、评分、出版时间、折扣筛选 | ⚠️ 出版社 / 评分做成**前端过滤**（接口与表结构无对应参数）；出版时间因图书表无该字段**不做** |
| 「价格↑/↓」文案理解成本高 | ✅ 改为「价格从低到高 / 价格从高到低」；选中态为底色 + 边框双重信号 |
| 分页上一页/下一页没有禁用态 | ✅ 第一页「上一页」、末页「下一页」置灰（`.pg-btn.off`） |
| 没有筛选结果条 | ✅ 桌面顶部「共 N 本 + 已选条件 chips」，单个条件可点击移除 |

### 11.3 详情页 / 购物车（待第二批）

| 评审意见 | 处理结论 |
| --- | --- |
| 缩略图没有切换与放大 | 计划：缩略图切换主图 + 放大预览弹层（Esc / 点击遮罩关闭） |
| 加购后没有反馈与去购物车入口 | 计划：Toast + 「去购物车」按钮（沿用 `common/cart-action.js` 的既有链路） |
| 数量没有库存上限 | 计划：步进器边界置灰（详情页已有 `stockLimit` 逻辑，补 disabled 样式） |
| 服务标签缺图标 | 计划：配 12px SVG 线性图标（库存 / 正品 / 发货 / 退货） |
| 评价缺星级筛选 | ⚠️ 接口无 rating 参数：详情页在已加载评价内过滤，完整筛选放到「全部评价」页 |
| 缺相关推荐 | 计划：底部「看了又看」，取同分类图书（接口已支持 `categoryId`） |
| 购物车建议用 `<table>` 语义标签 | 计划：桌面表格用 CSS `display:table` + `role` 属性（uni-app 模板内直接写 `<table>` 有编译风险，需实测后决定） |
| 失效商品仍可勾选 | 计划：复选框置灰 + 「库存不足，无法结算」文案，且不参与合计 |
| 缺批量删除 | 计划：表头「批量删除选中」，二次确认后删除 |
| 缺移入收藏 | ⚠️ 需求范围明确不含收藏（无表无接口），**先不做**，避免空壳入口 |
| 合计缺运费提示 | ⚠️ 订单表无运费字段，改为「本店全场包邮」，不编造运费数字 |
| 猜你喜欢是静态占位 | 计划：按购物车图书的分类取同分类推荐，副标题注明推荐依据 |
