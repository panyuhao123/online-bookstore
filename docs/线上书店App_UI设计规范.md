# 线上书店 App · UI 设计规范

> 适用版本：bookstore-app（uni-app Vue3，非 CLI）　|　基准屏宽：750rpx（iPhone 6/7/8，逻辑 375px）
> 本规范为毕设移动端改造的唯一视觉口径，配套可交互设计稿见 `docs/ui-design-preview.html`。

---

## 一、竞品调研与可借鉴要点

调研对象：当当（图书电商标杆）、京东读书（电商 + 阅读）、微信读书（阅读体验标杆）。

| 维度 | 当当 | 京东读书 | 微信读书 | **本 App 借鉴决策** |
| --- | --- | --- | --- | --- |
| 主色策略 | 白 + 淡蓝底，红色做价格/促销 | 白 + 橙，橙为行动色 | 蓝白（微信生态色），极度克制 | **白 + 中性灰底，红管「钱」、橙管「路」**：红只出现在价格与主操作上，橙只出现在搜索、购物车等导航控件上（与 PC 商城端同一套色板） |
| 首页 IA | 搜索 → 分类导航 → 推荐位 → 榜单流 | 搜索 → Banner → 楼层推荐 | 书架优先，书城后置 | 搜索置顶 → 分类横滑 chips → 排序 → 图书流（保持现有结构，补排序与楼层感） |
| 列表形态 | 大图两列网格（图书必看封面） | 两列网格 + 单行榜单 | 单行卡片（书名优先） | **分类页两列网格、首页单行大卡**（封面 + 作者 + 价格 + 销量，信息密度高于竞品） |
| 详情页 | 封面 + 价格 + 促销标签 + 简介 + 书评 | 封面 + 试读 + 价格 + 详情 | 封面 + 简介 + 目录 | 封面收窄到 4:5（现 1:1 过高），价格区强化，补**库存标签/售罄态** |
| 购物车 | 勾选 + 步进器 + 底栏结算 | 同，含失效商品分区 | 不涉及 | 保持底栏结算，补**库存不足灰化 + 实时合计本地计算** |
| 结算 | 地址 → 清单 → 金额 → 提交 | 同 + 配送方式 | 不涉及 | 保持，补**地址为空的引导态**与提交 loading |
| 个人中心 | 头像卡 + 订单状态宫格 | 头像卡 + 资产宫格 | 极简列表 | **头像卡 + 订单状态四宫格**（待支付/已支付/已发货/已完成），一眼看到待办 |
| 反馈机制 | Toast + 空态插画 | Toast + 骨架屏 | 状态可见性做得最好 | **统一四态**：加载骨架 / 空态（含引导按钮）/ 失败重试 / 成功 Toast |

**三条可落地的核心结论：**

1. **封面是图书电商的第一信息**。网格页封面占比 ≥ 60%，单行页封面固定 160×214rpx（3:4 开本比例，符合真实书脊比例）。
2. **价格必须是最强的视觉锚点**，但只允许一处最强——列表页价格字重 600、色值品牌红；详情页放大到 48rpx；同一屏不出现第二处红色强调。
3. **状态可见性是体验分水岭**。竞品无一例外做了骨架屏 / 空态插画 / 失败重试，本 App 原本只有一行灰字，这是本次改造增益最大的部分。

## 二、设计 Token

### 2.1 色彩系统

色板与 `bookstore-web`（PC 商城端）共用一套值，两端只差尺度（rpx vs px）。
分工原则：**红 = 钱，橙 = 路**——价格、主按钮、选中态用红；搜索、购物车、导航类控件用橙。
橙绝不用于结算按钮，红绝不用于导航控件，避免用户把两个高饱和色读成同一件事。

| 角色 | Token | 色值 | 用途 | 对比度（vs 白底） |
| --- | --- | --- | --- | --- |
| 品牌主色 | `$brand` | `#ff2832` | 价格、主按钮、选中态、Tab 选中 | 3.9:1（仅用于大字与大色块） |
| 主色浅 | `$brand-light` | `#ff6b71` | 渐变浅端、按压态 | — |
| 主色深 | `$brand-dark` | `#e6162d` | 按压加深、榜单名次块 | 4.6:1 ✅ AA |
| 主色淡底 | `$brand-weak` | `#fff1f0` | 选中态底、促销标签底、价格区块底 | — |
| 导航橙 | `$orange` | `#ff6f00` | 搜索框、购物车入口与角标 | 3.0:1（图形元素门槛） |
| 导航橙浅 | `$orange-light` | `#ff8f00` | 橙色渐变端点 | — |
| 导航橙深 | `$orange-dark` | `#e65f00` | 橙色图标线条（在白底上更实） | 3.2:1（图形元素门槛） |
| 导航橙淡底 | `$orange-weak` | `#fff4e8` | 橙系提示底 | — |
| 主文字 | `$text-main` | `#333333` | 标题、书名、金额 | 12.6:1 ✅ AAA |
| 正文 | `$text-regular` | `#666666` | 作者、描述、表单值 | 5.7:1 ✅ AA |
| 辅助文字 | `$text-sub` | `#8c9099` | 时间、销量、占位 | 4.6:1 ✅ AA |
| 占位符 | `$text-placeholder` | `#b9bdc4` | input placeholder | 3.1:1（非文本语义） |
| 页面底 | `$bg-page` | `#f5f5f5` | 页面背景（与 PC 同一片灰） | — |
| 卡片底 | `$bg-card` | `#ffffff` | 卡片、底栏 | — |
| 填充底 | `$bg-fill` | `#f7f7f7` | 输入框、次要按钮、表头 | — |
| 卡片边框 | `$border-color` | `#e5e5e5` | 卡片 1rpx 边框、列表分割线（**主要分层手段**） | — |
| 细分隔 | `$border-light` | `#f0f0f0` | 卡片内部细分隔 | — |
| 骨架底 | `$bg-skeleton` | `#ededed` | 骨架屏块 | — |
| 成功 | `$success` | `#2f9e44` | 支付成功、连接正常 | 3.7:1（大字）/ 图标 |
| 警告 | `$warning` | `#e8912a` | 本地购物车提示 | — |
| 价格 | `$price-color` | `#ff2832` | 与品牌同色，靠字重与字号拉开层级 | 3.9:1（行卡 38rpx 大字达标） |

> **无障碍**：正文类文字对白底 ≥ 4.5:1（WCAG AA）。主红 `#ff2832` 对白底仅 3.9:1，
> 因此它只允许出现在 ≥ 30rpx 的加粗文字、实底按钮（白字对比度同样 3.9:1，靠字号与字重补偿）
> 与图形元素上，不得用于小字正文。此约束与 PC 商城端一致，改主色时两端要同步。

### 2.2 字体层级（rpx / 750 基准）

| 级别 | Token | 字号 | 字重 | 行高 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| D1 | `$fs-3xl` | 48rpx | 700 | 1.3 | 详情页价格 |
| D2 | `$fs-2xl` | 40rpx | 600 | 1.35 | 页面主标题、状态头 |
| T1 | `$fs-xl` | 34rpx | 600 | 1.4 | 卡片书名、区块标题 |
| T2 | `$fs-lg` | 30rpx | 600 | 1.45 | 按钮文字、Tab 选中 |
| B1 | `$fs-md` | 28rpx | 400 | 1.6 | 正文、表单输入 |
| B2 | `$fs-base` | 26rpx | 400 | 1.6 | 次要正文、菜单项 |
| C1 | `$fs-sm` | 24rpx | 400 | 1.5 | 价格、辅助信息 |
| C2 | `$fs-xs` | 22rpx | 400 | 1.4 | 标签、角标、时间戳 |

> **移动端可读性底线**：正文 ≥ 26rpx（13px），辅助信息 ≥ 22rpx（11px），低于此值在 5 寸机上不可读。原代码 22rpx 用于"已售/库存"等有效信息，本次统一提到 24rpx。

### 2.3 间距系统（8rpx 基准栅格）

```
$sp-1  8rpx    $sp-2  16rpx   $sp-3  24rpx   $sp-4  32rpx
$sp-5  40rpx   $sp-6  48rpx   $sp-8  64rpx   $sp-10 80rpx
```

固定用法：页面左右边距 `24rpx`；卡片内边距 `24rpx`；卡片间距 `20rpx`；区块间距 `32rpx`；列表项上下 `24rpx`。

### 2.4 圆角与阴影

**分层靠边框，不靠阴影**（与 PC 商城端一致）。静态卡片没有阴影，白底 + 1rpx `$border-color`
边框就能在白底上把卡片和页面底分开；阴影只留给真正悬浮的固定底栏与按压反馈。

| Token | 值 | 用途 |
| --- | --- | --- |
| `$radius-sm` | 4rpx（2px） | 封面、小标签、促销角标 |
| `$radius-md` | 8rpx（4px） | 输入框、图片 |
| `$radius-lg` | 8rpx（4px） | 卡片（原 20rpx 已压缩） |
| `$radius-btn` | 8rpx（4px） | 按钮、Chip、搜索框（**替代原胶囊 999rpx**） |
| `$radius-pill` | 999rpx | **仅限真圆形元素**：轮播圆点、数字角标、步进器、评分分布条、头像 |
| `$shadow-card` | `none` | 静态卡片不使用 |
| `$shadow-card-hover` | `0 8rpx 24rpx rgba(0,0,0,.10)` | 按压/悬浮反馈 |
| `$shadow-float` | `0 -4rpx 20rpx rgba(0,0,0,.06)` | 固定底栏（配合 1rpx 上边框） |

> **为什么移动端也去胶囊**：PC 端全站直角，若 APP 仍用 999rpx 胶囊按钮，
> 两端截图并排放会像两个产品。移动端把圆角压到 4px 既能与 PC 对上语言，
> 又不像 0 圆角那样在触屏上显得生硬；胶囊只保留给天生就是圆形的元素（圆点、角标）。

### 2.5 触控与动效

- **最小触控区 88rpx（44px）**：步进器按钮从 48rpx → 56rpx、外扩点击热区；删除/编辑等图标按钮统一 88rpx 见方热区。
- 按压反馈：`.tap-scale` → `transform: scale(.97)`，120ms。
- 页面转场、Toast 沿用系统，不自定义（uni-app App 端自定义动画易掉帧）。

### 2.6 图标风格

- 统一**线性图标、2rpx 描边、圆头端点**，视觉尺寸 40rpx，与文字基线对齐。
- 本项目不引入图标库（保持零依赖），改用 **uni-app 内置字体字符 + 自绘 SVG 数据 URI** 两种方案：TabBar 沿用 PNG，页面内图标用「文字字符 + 圆形容器」。

## 三、组件规范

### 3.1 按钮

| 类型 | 规格 | 样式 |
| --- | --- | --- |
| Primary | 高 88rpx，圆角 8rpx，字 30rpx/600 | 品牌底 + 白字；禁用 `#d9d9d9` 底 `#ffffff` 字、`opacity:1`（不用透明，避免误认为可点） |
| Outline | 高 72rpx，圆角 8rpx，字 28rpx | 白底 + `$brand` 字 + 1rpx 主色边 |
| Text | 高 64rpx，字 26rpx | 主色文字，无边框 |
| Danger | 同 Primary | `$error` 底 |

**橙色不用于按钮**。购物车、搜索这类「去某处」的入口用橙色（图标或描边），
一旦落到「结算 / 提交订单 / 立即购买」这种真金白银的动作上，必须换成红。

按压态：`opacity: .85`，无位移（App 端避免重排）。

### 3.2 卡片

白底、`$radius-lg`（8rpx）、**1rpx `$border-color` 边框、无阴影**、内边距 24rpx。
列表型卡片按压降为 `$bg-page` 底。全局类 `.card` / `.card-flush` 与 `@mixin card` 三处同源，
改卡片形态只改 `uni.scss` 的 mixin 即可。

### 3.3 图书卡（两种形态）

- **行卡 Row**（首页/订单）：封面 160×214rpx（3:4），右侧信息区 `flex:1`：书名 2 行截断（34rpx/600）→ 作者·出版社（24rpx）→ 价格 + 销量。
- **网格卡 Grid**（分类）：宽 `calc((750rpx - 24rpx*2 - 20rpx)/2)`，封面 100% 宽 × 4:5，书名 2 行截断（28rpx）。
- **价格规格**（两端统一）：`¥` 符号用 24rpx/700 贴着数字基线，数字用 **38rpx/700**（比书名 34rpx 大一级，靠字号而非颜色抢注意力）。原实现符号与数字同量级、数字仅 34rpx，在卡片里不构成价格焦点。
- **促销标签**分两档：`仅剩 N 件` 这类催促信号用实红底白字；`热销` `新书` 这类正向标签用浅红底（`$brand-weak`）+ 红字，避免卡片上出现一片同强度的红块。

**封面素材规范（真实封面）**

封面是列表页的第一信息，因此**只允许真实书封，禁止排版占位图**（浅色渐变底 + 书名文字块）。
演示数据集 102 本已全部换为豆瓣收录的真实封面（唯一例外见下）。

| 约束 | 口径 |
| --- | --- |
| 形态 | 竖版实拍开本，宽高比落在 **0.55–0.95**（推荐 3:4）；方图、横图、宣传 banner 一律不合格 |
| 分辨率 | 宽 ≥ **200px**（列表渲染约 80×107 CSS px，2 倍屏需 160px，200 留余量）；低于此值详情页会发虚，但**真实优于清晰**，宁可略糊不返回占位图 |
| 落位 | APP `static/cover/<file>.jpg` 与后端 `upload/cover/<file>.jpg` **同名同字节**，两处必须同步写入 |
| 渲染 | `cover-box` 统一 `mode="aspectFill"`，底色 `$bg-fill`；加载失败降级为「渐变底 + 书名」，不出现破图 |
| 维护 | `python tools/refetch_mock_covers.py --scan` 全量体检（占位图 / 方图 / 低分辨率 / 比例异常）；带书名参数可单独重抓 |

> 已知例外：`下厨房：家常菜`（`bk4436f88714.jpg`）为数据集内自拟书目，豆瓣各检索口径（书名、作者、出版社组合）均无收录，
> 保留排版占位封面。演示时如被问到，按「数据集自拟条目、无对应实体书」解释。

### 3.4 状态反馈四件套（新增）

| 状态 | 组件 | 表现 |
| --- | --- | --- |
| 加载中 | 骨架屏 | 封面块 + 3 条文字条，`$bg-skeleton` 底 + 1.2s 呼吸动画 |
| 空数据 | 空态 | 图标区 + 主文案（28rpx）+ 副文案（24rpx）+ 引导按钮 |
| 请求失败 | 错误态 | 图标区 + 文案 + 「重试」按钮（触发 reload） |
| 操作成功 | Toast | `uni.showToast`，成功用 `icon:'success'`，其余 `icon:'none'` |

## 五、落地映射（Token → 代码）

| 规范项 | 落地位置 |
| --- | --- |
| 色彩/字号/间距/圆角/阴影 Token | `uni.scss`（SCSS 变量，全量注入） |
| 全局基础样式、通用类、状态四件套 | `App.vue` `<style>`（非 scoped，全局生效） |
| 页面级样式 | 各页 `<style lang="scss" scoped>`，仅引用 Token，禁止硬编码色值 |
| 交互与状态逻辑 | 各页 `<script setup>`，保持现有 API 与数据结构不变 |
| Tab 图标配色 | `static/tabbar/*.png` 按 `$text-sub`（未选）/ `$brand`（选中）重着色，改主色需重新生成 |
| 两处 JS 内色值 | `pages/address/edit.vue`、`pages/review/edit.vue` 的 `SWITCH_COLOR`（`switch` 只吃色值字符串，取不到 Token，改主色要手动同步） |
| 封面素材 | `bookstore-app/static/cover/*.jpg` + `bookstore-server/upload/cover/*.jpg`（同名同字节）；体检/重抓工具 `tools/refetch_mock_covers.py` |
