# 线上书店 App · UI 设计规范

> 适用版本：bookstore-app（uni-app Vue3，非 CLI）　|　基准屏宽：750rpx（iPhone 6/7/8，逻辑 375px）
> 本规范为毕设移动端改造的唯一视觉口径，配套可交互设计稿见 `docs/ui-design-preview.html`。

---

## 一、竞品调研与可借鉴要点

调研对象：当当（图书电商标杆）、京东读书（电商 + 阅读）、微信读书（阅读体验标杆）。

| 维度 | 当当 | 京东读书 | 微信读书 | **本 App 借鉴决策** |
| --- | --- | --- | --- | --- |
| 主色策略 | 白 + 淡蓝底，红色做价格/促销 | 白 + 橙，橙为行动色 | 蓝白（微信生态色），极度克制 | **低饱和中性底 + 高饱和朱砂红做行动色**：既有书店的人文感，又保留电商的转化色 |
| 首页 IA | 搜索 → 分类导航 → 推荐位 → 榜单流 | 搜索 → Banner → 楼层推荐 | 书架优先，书城后置 | 搜索置顶 → 分类横滑 chips → 排序 → 图书流（保持现有结构，补排序与楼层感） |
| 列表形态 | 大图两列网格（图书必看封面） | 两列网格 + 单行榜单 | 单行卡片（书名优先） | **分类页两列网格、首页单行大卡**（封面 + 作者 + 价格 + 销量，信息密度高于竞品） |
| 详情页 | 封面 + 价格 + 促销标签 + 简介 + 书评 | 封面 + 试读 + 价格 + 详情 | 封面 + 简介 + 目录 | 封面收窄到 4:5（现 1:1 过高），价格区强化，补**库存标签/售罄态** |
| 购物车 | 勾选 + 步进器 + 底栏结算 | 同，含失效商品分区 | 不涉及 | 保持底栏结算，补**库存不足灰化 + 实时合计本地计算** |
| 结算 | 地址 → 清单 → 金额 → 提交 | 同 + 配送方式 | 不涉及 | 保持，补**地址为空的引导态**与提交 loading |
| 个人中心 | 头像卡 + 订单状态宫格 | 头像卡 + 资产宫格 | 极简列表 | **头像卡 + 订单状态四宫格**（待支付/已支付/已发货/已完成），一眼看到待办 |
| 反馈机制 | Toast + 空态插画 | Toast + 骨架屏 | 状态可见性做得最好 | **统一四态**：加载骨架 / 空态（含引导按钮）/ 失败重试 / 成功 Toast |

**三条可落地的核心结论：**

1. **封面是图书电商的第一信息**。网格页封面占比 ≥ 60%，单行页封面固定 160×214rpx（3:4 开本比例，符合真实书脊比例）。
2. **价格必须是最强的视觉锚点**，但只允许一处最强——列表页价格字重 600、色值品牌红；详情页放大到 48rpx；同一屏不出现第二处红色强调。
3. **状态可见性是体验分水岭**。竞品无一例外做了骨架屏 / 空态插画 / 失败重试，本 App 原本只有一行灰字，这是本次改造增益最大的部分。

## 二、设计 Token

### 2.1 色彩系统

| 角色 | Token | 色值 | 用途 | 对比度（vs 白底） |
| --- | --- | --- | --- | --- |
| 品牌主色 | `$brand` | `#C8362F` | 主按钮、选中态、Tab 选中 | 5.9:1 ✅ AA |
| 主色浅 | `$brand-light` | `#E4574E` | 渐变端点、按压态 | — |
| 主色淡底 | `$brand-weak` | `#FDECEA` | 标签底、弱提示底 | — |
| 主文字 | `$text-main` | `#1F2126` | 标题、书名、金额 | 15.3:1 ✅ AAA |
| 正文 | `$text-regular` | `#4E5259` | 作者、描述、表单值 | 8.2:1 ✅ AAA |
| 辅助文字 | `$text-sub` | `#8C9099` | 时间、销量、占位 | 4.6:1 ✅ AA |
| 占位符 | `$text-placeholder` | `#B9BDC4` | input placeholder | 3.1:1（非文本语义） |
| 页面底 | `$bg-page` | `#F4F5F7` | 页面背景 | — |
| 卡片底 | `$bg-card` | `#FFFFFF` | 卡片、底栏 | — |
| 分割线 | `$border-color` | `#EDEEF0` | 1rpx 分割 | — |
| 骨架底 | `$bg-skeleton` | `#EBECEF` | 骨架屏块 | — |
| 成功 | `$success` | `#2F9E44` | 支付成功、连接正常 | 3.7:1（大字）/ 图标 |
| 警告 | `$warning` | `#E8912A` | 本地购物车提示 | — |
| 价格 | `$price` | `#C8362F` | 与品牌同色，靠字重区分 | 5.9:1 ✅ AA |

> **无障碍**：全部正文色对白底 ≥ 4.5:1（WCAG AA）。主按钮白字对 `#C8362F` 为 5.9:1。原 `#C0392B` 偏暗且蓝紫味重，提亮为朱砂红 `#C8362F`，更贴合纸质书意象，同时提升按钮文字可读性。

### 2.2 字体层级（rpx / 750 基准）

| 级别 | Token | 字号 | 字重 | 行高 | 典型用途 |
| --- | --- | --- | --- | --- | --- |
| D1 | `$fs-3xl` | 48rpx | 700 | 1.3 | 详情页价格 |
| D2 | `$fs-2xl` | 40rpx | 600 | 1.35 | 页面主标题、状态头 |
| T1 | `$fs-xl` | 34rpx | 600 | 1.4 | 卡片书名、区块标题 |
| T2 | `$fs-lg` | 30rpx | 600 | 1.45 | 按钮文字、Tab 选中 |
| B1 | `$fs-md` | 28rpx | 400 | 1.6 | 正文、表单输入 |
| B2 | `$fs-base` | 26rpx | 400 | 1.6 | 次要正文、菜单项 |
| C1 | `$fs-sm` | 24rpx | 400 | 1.5 | 价格、辅助信息 |
| C2 | `$fs-xs` | 22rpx | 400 | 1.4 | 标签、角标、时间戳 |

> **移动端可读性底线**：正文 ≥ 26rpx（13px），辅助信息 ≥ 22rpx（11px），低于此值在 5 寸机上不可读。原代码 22rpx 用于"已售/库存"等有效信息，本次统一提到 24rpx。

### 2.3 间距系统（8rpx 基准栅格）

```
$sp-1  8rpx    $sp-2  16rpx   $sp-3  24rpx   $sp-4  32rpx
$sp-5  40rpx   $sp-6  48rpx   $sp-8  64rpx   $sp-10 80rpx
```

固定用法：页面左右边距 `24rpx`；卡片内边距 `24rpx`；卡片间距 `20rpx`；区块间距 `32rpx`；列表项上下 `24rpx`。

### 2.4 圆角与阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `$radius-sm` | 8rpx | 封面、小标签 |
| `$radius-md` | 12rpx | 输入框、图片 |
| `$radius-lg` | 20rpx | 卡片（统一，原 16rpx 提升手感） |
| `$radius-pill` | 999rpx | 按钮、Chip、胶囊 |
| `$shadow-card` | `0 2rpx 12rpx rgba(31,33,38,.05)` | 卡片静态 |
| `$shadow-card-hover` | `0 8rpx 24rpx rgba(31,33,38,.10)` | 卡片按压 |
| `$shadow-float` | `0 -4rpx 20rpx rgba(31,33,38,.08)` | 固定底栏 |

### 2.5 触控与动效

- **最小触控区 88rpx（44px）**：步进器按钮从 48rpx → 56rpx、外扩点击热区；删除/编辑等图标按钮统一 88rpx 见方热区。
- 按压反馈：`.tap-scale` → `transform: scale(.97)`，120ms。
- 页面转场、Toast 沿用系统，不自定义（uni-app App 端自定义动画易掉帧）。

### 2.6 图标风格

- 统一**线性图标、2rpx 描边、圆头端点**，视觉尺寸 40rpx，与文字基线对齐。
- 本项目不引入图标库（保持零依赖），改用 **uni-app 内置字体字符 + 自绘 SVG 数据 URI** 两种方案：TabBar 沿用 PNG，页面内图标用「文字字符 + 圆形容器」。

## 三、组件规范

### 3.1 按钮

| 类型 | 规格 | 样式 |
| --- | --- | --- |
| Primary | 高 88rpx，圆角 44rpx，字 30rpx/600 | 品牌底 + 白字；禁用 `#D8D9DC` 底 `#FFFFFF` 字、`opacity:1`（不用透明，避免误认为可点） |
| Outline | 高 72rpx，圆角 36rpx，字 28rpx | 白底 + `#C8362F` 字 + 1rpx 主色边 |
| Text | 高 64rpx，字 26rpx | 主色文字，无边框 |
| Danger | 同 Primary | `#E03131` 底 |

按压态：`opacity: .85`，无位移（App 端避免重排）。

### 3.2 卡片

白底、`$radius-lg`、`$shadow-card`、内边距 24rpx。列表型卡片按压降为 `$bg-page` 底。

### 3.3 图书卡（两种形态）

- **行卡 Row**（首页/订单）：封面 160×214rpx（3:4），右侧信息区 `flex:1`：书名 2 行截断（34rpx/600）→ 作者·出版社（24rpx）→ 价格（34rpx/600 品牌色）+ 销量。
- **网格卡 Grid**（分类）：宽 `calc((750rpx - 24rpx*2 - 20rpx)/2)`，封面 100% 宽 × 4:5，书名 2 行截断（28rpx），价格 30rpx。

### 3.4 状态反馈四件套（新增）

| 状态 | 组件 | 表现 |
| --- | --- | --- |
| 加载中 | 骨架屏 | 封面块 + 3 条文字条，`$bg-skeleton` 底 + 1.2s 呼吸动画 |
| 空数据 | 空态 | 图标区 + 主文案（28rpx）+ 副文案（24rpx）+ 引导按钮 |
| 请求失败 | 错误态 | 图标区 + 文案 + 「重试」按钮（触发 reload） |
| 操作成功 | Toast | `uni.showToast`，成功用 `icon:'success'`，其余 `icon:'none'` |

## 五、落地映射（Token → 代码）

| 规范项 | 落地位置 |
| --- | --- |
| 色彩/字号/间距/圆角/阴影 Token | `uni.scss`（SCSS 变量，全量注入） |
| 全局基础样式、通用类、状态四件套 | `App.vue` `<style>`（非 scoped，全局生效） |
| 页面级样式 | 各页 `<style lang="scss" scoped>`，仅引用 Token，禁止硬编码色值 |
| 交互与状态逻辑 | 各页 `<script setup>`，保持现有 API 与数据结构不变 |
